# Ecom Team Project

 نبذة عن المشروع

Ecom موقع تجارة إلكترونية متعدد الصفحات، أنجزناه بشكل جماعي باستخدام HTML وCSS وBootstrap وJavaScript. شارك أعضاء الفريق في كتابة أكواد الصفحات والأقسام وتجميعها ضمن مشروع واحد، مع استخدام ملفات CSS وJavaScript مشتركة للحفاظ على تنسيق الموقع ووظائفه.

يضم الموقع عدة تصاميم للصفحة الرئيسية، وصفحات للمنتجات والمتجر والبائعين والمدونة، بالإضافة إلى صفحات مثل من نحن، تواصل معنا، وتسجيل الدخول. استخدمنا GitHub لمشاركة التعديلات ودمج عمل الفريق.

 About the Project

Ecom is a multi-page e-commerce website built collaboratively with HTML, CSS, Bootstrap, and JavaScript. Team members contributed page and section code, then combined their work into one project. CSS and JavaScript files are shared across the site to support consistent styling and functionality.

The website includes multiple homepage layouts, product and shop pages, vendor pages, a blog, and informational pages such as About Us, Contact Us, and Login. We used GitHub to share changes and integrate the team's work.
